# proyecto-interculturtal-schonthal
Este proyecto está dirigido por los docentes Verónica Almirón y Lucas Leonel de la Peña en el Colegio Schönthal. Su objetivo es transformar la barrera lingüística de la comunidad estudiantil coreana en una oportunidad de integración intercultural, utilizando la literatura y la historia comparada para fortalecer la identidad y el español.
